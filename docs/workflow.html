2 자동 스케줄

🌅 일일 브리핑

평일 매일 아침 자동 실행. 시장 데이터 분석 → 추천 종목 카카오톡 전송.

cron: '30 21 * * 0-4' (UTC) = 평일 06:30 KST

📅 주간 리포트

매주 일요일 통계 요약. 월별 적중률, 평균 수익률, 승률.

cron: '0 0 * * 0' (UTC) = 일요일 09:00 KST

+ 휴장일 자동 스킵: market_calendar.py가 한국 공휴일 + KRX 연말폐장 감지

3 데이터 수집

📈 KIS 시장 데이터

한국투자증권 Open API로 시세, 거래량, 투자자별 매매동향, 프로그램 매매 수집.

KOSPI/KOSDAQ 지수 거래량 순위 50개 일봉 60일치 외국인 + 기관 매매

📰 Naver 뉴스

10개 키워드 × 15건 = 150건 raw → 가중치 + 중복제거 + 감성 분석.

연합 +3 / 한경 +2 / 매경 +2 블로그/광고 -2 24h 트렌드 + 감성 Δ

🗄️ DB 조회

최근 7일 추천 이력을 AI에 회피 힌트로 전달 (동일 종목 반복 방지).

4 시장 상태(regime) 판단 → 가중치 결정

5개 지표 점수화 → bullish / sideways / bearish 분류 → 가중치 자동 조정

시장 상태 외국인 수급 기관 수급 거래대금 증가율

🟡 Sideways 혼조세 40%30%30%

5 기술적 스크리닝 + AI 분석

🔬 스크리닝 (점수 0~100)

KIS 거래량 상위 50개 → ETF 필터 → 5일 외국인/기관 누적 + 거래대금 증가율 기반 점수.

외국인 비중 → 0~40점 기관 비중 → 0~30점 거래대금 증가율 → 0~30점

🤖 AI 종합 (gpt-4o-mini)

뉴스 + 기술 후보 + 시장 상태 + 회피 종목 → JSON 13개 추천 생성. 검증 후 부족하면 자동 재시도.

뉴스 enriched 컨텍스트 기술 후보 20개 + 시그널 최대 2회 자동 재추천

6 검증 — 4단계 통과해야 추천 자격

AI 환각(hallucination) 방지 + 거래 가능 종목만 선별

1
KIS 종목코드 존재 여부

get_stock_price 응답으로 실재 코드인지 확인. 미인식 코드는 즉시 드롭.

2
종목명 정확성

KIS 일봉 endpoint의 hts_kor_isnm으로 canonical 이름 확보. AI가 잘못 매칭한 이름 자동 정정 (예: "한국전력"으로 표시한 005740 → 실제 "크라운제과").

3
ETF/ETN/SPAC 여부

브랜드 prefix (KODEX/TIGER/KIWOOM 등) + 키워드 (액티브/선물지수/인버스/레버리지) + KIS 마켓 구분 다중 필터.

4
거래 가능 여부

KIS 상태 코드로 관리종목/거래정지/정리매매/시장경고/임시정지 모두 차단. iscd_stat_cls_code 51~59 ❌ temp_stop_yn = Y ❌ sltr_yn = Y ❌ mrkt_warn_cls_code 02/03 ❌

검증 통과 < 5개면 AI가 자동으로 다시 호출됨 (탈락 코드를 회피 목록에 추가)

7 점수 필터 — 가변 추천 개수

신뢰도 점수(0~100) ≥ 50 종목만 통과. 강세장이면 8~10개, 약세장이면 0~3개.

강한 시그널

70+

평균

50~70

제외

< 50

9 14일 추적 — MFE / MAE / Final

MFE

Max Favorable Excursion
14일 중 최고 상승률

MAE

Max Adverse Excursion
14일 중 최대 하락률

Final

14일 후 최종 수익률
3% 이상 = 적중

매일 가격 기록 → 8개 티어 분류 (+30%↑ / +10~30 / +5~10 / 0~5 / -5~0 / -10~-5 / -30~-10 / ≤-30) → 월별 집계

11 Historical Backtest — 과거 일자 시뮬레이션

특정 날짜 구간에 시스템을 재실행한 것처럼 시뮬레이션해서 전략 검증.

⏱️ 어떻게 동작

유니버스 종목의 OHLCV + 투자자 매매동향을 한 번 캐싱한 뒤, 과거 일자별로 그 시점까지의 데이터만으로 점수 재계산 → top N 선정 → 14일 forward 가격으로 성과 측정.

no lookahead technical_screener 그대로 재사용

📈 측정 지표

승률 — final > 0 비율
평균 수익률
샤프비율 — avg / stdev (raw)
MDD — 일자별 평균 누적 곡선의 최대 낙폭

CLI 사용 예: python historical_backtest.py --start 2026-05-08 --end 2026-05-22 --top-n 10 --min-score 50
제약: KIS 투자자 데이터가 ~30일 한도라 백테스트 기간 자동 30일 cap, 뉴스 입력은 제외 (수급+기술만).
